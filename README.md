# news-image-20261125

A newspaper front page that sums up Wednesday 25 November 2026 in six stories — the Houthi strike on Riyadh's tallest tower, Ukraine's strikes on Russian ships, the CIA and ODNI cyber breach, Iran's chemical-weapons programme, Huawei's US conviction, and the Army's Iowa detonation — drawn from scratch with a Python script.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `entry.png` to `out/entry.png`.
